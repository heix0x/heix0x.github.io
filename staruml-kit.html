使用说明

准备

  • 本机已安装 StarUML 5.0.2 或更高版本
  • 一个浏览器（Edge / Chrome 均可，无需联网）

五步生成一张流程图

  1. 点顶部 「复制给 DeepSeek 的说明」。
  2. 打开 DeepSeek 网页，粘贴这段说明，再贴上题目。
  3. 复制 DeepSeek 返回的文字，粘贴到左侧输入框，右侧立即出现预览。
  4. 点 「生成并下载 .mdj」。
  5. 完全退出 StarUML，再双击下载的 .mdj 文件。
第 5 步不能省。StarUML 在打开状态下会把内存里的旧内容写回文件，看起来像生成失败。

语法速查

节点写法：框里的文字 | 类型

类型形状用途
terminator圆头框开始 / 结束
process矩形处理、赋值、计算
decision菱形判断
data平行四边形输入 / 输出

连线写法：A -> B

写法说明
A -> B连接两个框
A -> B : 是线上带标签
A -> B : back循环回边，自动绕外侧
A -> B : 是, left指定从左侧出线

导出图片（交作业用）

在 StarUML 中打开 .mdj，菜单 File → Export As → PNG，在对话框里把宽度设为 2000 px 以上，导出的图清晰可打印。

常见问题

现象处理
提示「起点没有定义」连线里的名字与节点行不一致，检查空格和全半角。
下载后打不开先完全退出 StarUML，再双击文件。
所有框叠在左上角刷新页面重新生成；仍有问题看左侧的报错行。
连线穿过框给该连线加上 back。

原理

.mdj 文件分两层：模型层记录有哪些框、怎么连；视图层记录每个框的坐标和每条线的拐点。StarUML 不做自动排版，坐标必须提前算好。

本工具让 AI 只输出框和连线（十几行文字），坐标、编号、文件结构由页面内的代码生成。

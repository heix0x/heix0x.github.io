软件工程在读，方向是后端。

## 项目

**[HaxOJ 微服务后端](https://github.com/heix0x/haxoj-backend-microservice)**
在线判题系统的后端。Spring Cloud Alibaba + Nacos + OpenFeign，用户、题目、判题拆成三个独立服务。

**[代码沙箱](https://github.com/heix0x/haxoj-code-sandbox)**
隔离执行用户提交的 Java 代码。黑名单 + SecurityManager + Docker 容器，三层。

**[前端](https://github.com/heix0x/haxoj-frontend)**
Vue 3 + TypeScript + Vite，题目浏览、在线写题、判题结果查看。
